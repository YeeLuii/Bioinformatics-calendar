## 本机生产切换的独立核验

集成负责人完成备份与服务切换后，独立质控角色仅执行读取和散列比较，没有向真实工作区发送写入请求。私有备份和读回快照保留在本机，不进入公共仓库。

- 逐个重新计算切换前备份与当前生产目录中 9 个元数据文件的 SHA-256，均与备份清单一致；没有仅采信集成负责人的布尔检查结果。
- 对比切换前后项目 ID 集合与全部原有字段，保持一致；新增字段仅由新版读取时兼容补足。
- 全部卡片内容、位置、文件夹关系和桌面 revision 一致；待办 ID 集合及全部原有字段一致。
- 实际 GET 部署健康、项目、任务、桌面和 OpenAPI 接口，确认服务为 1.2.0；实例标识与切换验证记录一致，当前项目、任务和桌面响应与切换后快照一致。
- 生产只读计数为 16 个项目、57 张卡片和 3 条日程。集成负责人额外在生产浏览器打开甘特图，显示 3 项任务，未捕获页面 JavaScript 错误；此过程没有编辑真实项目。
- 32 个已部署运行时代码/前端资源与本轮源文件的 SHA-256 一致。验收说明等文档随后同步，不影响已验证的运行时代码。
- 检查未连接科研服务器，未读取研究文件内容，未移动或删除数据。科研进程未被纳入服务启停操作。

## 验收边界

独立检查 Agent 负责代码/数据契约、合成工作区行为、截图视觉检查以及生产切换后的只读散列和读回复核。浏览器交互、服务启停和升级备份由集成负责人执行并提供记录，避免多个角色争用浏览器或进程。上述结论分别注明直接检查和协作观察的范围。
