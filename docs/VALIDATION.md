# 版本验证记录

日期：2026-11-23；版本：1.0.0。

本机 Windows 上执行 `python -B -m unittest discover -p "test_*.py" -v`，13 项测试通过。

| 范围 | 验证内容 |
|---|---|
| 工作区隔离 | 空工作区无需科研目录、文件索引或第三方包 |
| 项目资料 | 新建、局部修改、相对目录、服务器地址可选、版本冲突 |
| 日程与布局 | 卡片和待办保存、备份、过期 revision 拒绝 |
| 会话关联 | UUID 校验、显式关联、关联版本冲突 |
| 迁移 | 打包后解压，独立导入和运行 HTTP/MCP，无原工作目录依赖 |
| MCP | 真实子进程 stdio 初始化、文档资源、项目工具；1.2 新增任务等操作的验证见 [升级验收](UPGRADE_QA.md) |
| 并发 | 两个 MCP 进程写入相同 revision，只有一个成功 |
| HTTP | Host/Origin/token 校验、项目归档恢复、摘要和日程接口 |
| 契约 | 提交的 OpenAPI 与运行时代码生成结果一致 |
| 字符编码 | 英文 Windows 的 cp1252 重定向环境下，中文帮助和工作区路径仍输出 UTF-8 |
| 演示 | 创建 6 个虚构项目和 4 个结果包；已有目录拒绝覆盖 |

浏览器检查覆盖桌面、计划本勾选并重载、文件夹展开、项目详情和结果视图；未观察到 JavaScript 异常。390 px 宽度下没有页面横向溢出。HTTP 示例脚本在演示工作区实际完成新建和汇总。

截图由真实演示页面生成，保存在 `docs/screenshots/`。没有使用个人研究路径、真实会话编号或未发表结果。

GitHub Actions 配置了 Windows/Linux × Python 3.9/3.12。远程运行情况以仓库 Actions 页面为准，不把本机验证等同于所有平台通过。macOS 原生导航和所有第三方 MCP 客户端没有逐一验证。
